Azure Trusted Signing Setup (Service Principal + Environment Variables)

Scope: Local development only. For GitHub Actions CI/CD, see github-oidc-trusted-signing.md.

This guide documents the repeatable setup for building signed MSI packages locally with Master Packager (mpdev).

Prerequisites

  • Azure subscription: 384be71e-d194-46cd-9a6b-d9bd71e91e0a
  • Tenant: 861f4c18-46fb-469e-84ba-832f4dc43d46
  • Code Signing account: KutanaBrochet
  • Certificate profile: KBCodeSigning
  • Local tools installed: az, task, mpdev

1) Create service principal (one-time)

$subId = "384be71e-d194-46cd-9a6b-d9bd71e91e0a"
$tenantId = "861f4c18-46fb-469e-84ba-832f4dc43d46"
$accountResourceId = "/subscriptions/$subId/resourceGroups/Code_Signing/providers/Microsoft.CodeSigning/codeSigningAccounts/KutanaBrochet"
$profileScope = "$accountResourceId/certificateProfiles/KBCodeSigning"
$appName = "kb-wordaddins-trustedsigning"

az login --tenant $tenantId
az account set --subscription $subId

$appId = az ad app create --display-name $appName --query appId -o tsv
az ad sp create --id $appId | Out-Null
$clientSecret = az ad app credential reset --id $appId --append --display-name "mpdev-signing" --years 1 --query password -o tsv
$spObjectId = az ad sp show --id $appId --query id -o tsv

2) Assign required roles

az role assignment create --assignee-object-id $spObjectId --assignee-principal-type ServicePrincipal --role "Artifact Signing Certificate Profile Signer" --scope "$profileScope" --subscription $subId
az role assignment create --assignee-object-id $spObjectId --assignee-principal-type ServicePrincipal --role "Artifact Signing Identity Verifier" --scope "$accountResourceId" --subscription $subId

3) Persist user-level environment variables

[Environment]::SetEnvironmentVariable("AZURE_TENANT_ID", $tenantId, "User")
[Environment]::SetEnvironmentVariable("AZURE_CLIENT_ID", $appId, "User")
[Environment]::SetEnvironmentVariable("AZURE_CLIENT_SECRET", $clientSecret, "User")
[Environment]::SetEnvironmentVariable("AZURE_TOKEN_CREDENTIALS", "prod", "User")

Close and reopen PowerShell after setting user-level variables.

4) Verify environment variables

Get-ChildItem Env:AZURE_* | Sort-Object Name

Expected entries:

  • AZURE_TENANT_ID
  • AZURE_CLIENT_ID
  • AZURE_CLIENT_SECRET
  • AZURE_TOKEN_CREDENTIALS=prod

5) Build MSI

task msi:word

6) Build server setup

Set the same four values in the build server secret store:

  • AZURE_TENANT_ID
  • AZURE_CLIENT_ID
  • AZURE_CLIENT_SECRET
  • AZURE_TOKEN_CREDENTIALS=prod

Then run task msi:word in the build job.

Troubleshooting

  • MissingSubscription: ensure --scope is a full resource path starting with /subscriptions/....
  • DefaultAzureCredential failed to retrieve a token: confirm all four environment variables are present in the process.
  • 403 Forbidden: role assignment is missing or not yet propagated. Wait a few minutes and retry.
  • Use verbose output for diagnostics:
mpdev build src/VSTO/WordAddIn/InstallerConfig.json --properties $.version=7.5.74 --verbose
